Multiplier Architectures

Binary multiplication in hardware has three stages: partial product generation (AND gates), partial product reduction (the core architectural choice), and final addition (carry-propagate adder). Architectures differ in how they organize reduction: sequentially reusing one adder, or in parallel across a 2D array or tree. The fundamental tradeoff: more combinational hardware buys less delay.

  • Shift-and-Add

    Sequential multiplication using one adder, reused n times.

    Tool topicMultipliers
  • Booth's Algorithm (Radix-2)

    Recodes the multiplier to skip runs of 1s and handle signed natively.

    Tool topicMultipliers
  • Array Multiplier

    Parallel n×n grid of adders with regular, layout-friendly structure.

    Tool topicMultipliers
  • Wallace Tree

    Logarithmic reduction tree: fastest with a CLA final adder.

    Tool topicMultipliers

Final-stage Adders

The final stage of any parallel multiplier is a carry-propagate addition of two rows. The choice of adder directly impacts total delay. These architectures also stand alone as general-purpose binary adders.

  • Ripple Carry Adder (RCA)

    Simplest adder: carry ripples bit-by-bit from LSB to MSB.

    Tool topicAdders
  • Carry Lookahead Adder (CLA)

    Computes all carries in parallel using generate/propagate logic.

    Tool topicAdders
  • Carry Select Adder (CSeA)

    Speculates on carry-in, computes both options, selects with a MUX.

    Tool topicAdders

Memory Hierarchy
